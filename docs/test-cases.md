# Career Knowledge Copilot - MVP 测试用例

本文件将产品需求转换成可重复检查的场景。执行者可以是开发者、测试人员或产品负责人。除另有说明外，测试前系统已启动，准备了一个含文字的 PDF 和一个非 PDF 文件。

| ID | 模块 | 前置条件 | 操作步骤 | 预期结果 |
| --- | --- | --- | --- | --- |
| TC-01 | 文档列表 | 无文档 | 打开文档页 | 显示空状态与上传入口，不报错。 |
| TC-02 | 上传 | 有小于 20 MB 的文字型 PDF | 选择并上传 PDF | 列表新增文件，先显示 `processing`。 |
| TC-03 | 上传 | 有处理成功的 PDF | 等待并刷新/轮询状态 | 状态变为 `ready`，可参与提问。 |
| TC-04 | 格式校验 | 有 `.docx` 或 `.txt` 文件 | 尝试上传该文件 | 前端阻止上传并提示仅支持 PDF；后端也返回 400。 |
| TC-05 | 大小校验 | 有大于 20 MB 的 PDF | 尝试上传 | 前端提示超出大小；不会创建文档记录。 |
| TC-06 | 解析失败 | 有扫描件或无可提取文字的 PDF | 上传并等待处理 | 状态为 `failed`，显示可理解的失败原因，不调用 OCR。 |
| TC-07 | 列表信息 | 至少一个已上传文件 | 查看文档列表 | 每行显示文件名、大小、上传时间、状态和删除入口。 |
| TC-08 | 删除取消 | 至少一个 ready 文档 | 点击删除，再在确认框中取消 | 文档仍在列表，后端数据未删除。 |
| TC-09 | 删除确认 | 至少一个 ready 文档 | 点击删除并确认 | 文档从列表消失，原文件和对应片段不再存在。 |
| TC-10 | 删除后检索 | 已删除唯一相关文档 | 针对该文档内容提问 | 回答不使用已删除文件，提示资料不足。 |
| TC-11 | 创建对话 | 浏览器无 `conversation_id` | 首次进入问答页 | 后端创建对话，前端保存并使用返回的 ID。 |
| TC-12 | 有依据问答 | 已有包含“Python”的 ready 文档 | 询问“资料中要求什么语言？” | 回答基于资料，包含正确文件名和页码。 |
| TC-13 | 多引用 | 两个文档均含相关内容 | 提问需要综合两份资料的问题 | 回答可列出多条引用，文件名与页码均正确。 |
| TC-14 | 无依据问答 | 有 ready 文档，但不含问题主题 | 提问无关问题 | 返回“没有找到足够依据”语义的提示，不编造，不显示虚假引用。 |
| TC-15 | 回答中加载态 | 有 ready 文档 | 发送一个问题，在响应返回前观察界面 | 问题立即显示，发送按钮禁用且有加载状态；完成后恢复。 |
| TC-16 | 防重复发送 | 正在生成回答 | 连续点击发送或按回车 | 同一问题只保存一条用户消息、只发起一次生成请求。 |
| TC-17 | 历史记录 | 已完成至少一轮问答 | 刷新问答页 | 同一对话的用户问题、助手回答和引用仍显示。 |
| TC-18 | 模型异常 | 模拟 Chat API 超时或 500 | 发送问题 | 用户问题被保存，页面显示可重试错误，不显示伪造回答或内部密钥。 |
| TC-19 | 处理中资料 | 所有文档均为 processing | 立即发送问题 | 不检索处理中资料，提示等待处理完成。 |
| TC-20 | 历史删除引用 | 回答已引用某文档 | 删除该文档后查看历史消息 | 历史回答保留，引用显示文件已删除或不可打开，不显示错误链接。 |
| TC-21 | 接口参数 | 使用不存在的文档/对话 ID 请求接口 | 调用相应 GET、DELETE 或消息接口 | 返回 404 JSON，前端给出用户可理解提示。 |
| TC-22 | 数据隔离 | 两个不同浏览器令牌各有一条对话 | 分别加载对话历史 | 每个浏览器只加载自己保存的当前对话，不互相混入消息。 |

## 验收记录模板

每次测试记录执行日期、执行人、环境、测试 ID、实际结果、是否通过和问题链接。所有 P0（上传、删除、带引用问答、历史恢复）用例通过后，才可进入 MVP 演示。
